# CookBook 🍽️

Reseptləri axtarmaq, kateqoriyalar üzrə kəşф etmək və hazırlanma qaydalarını oxumaq üçün Next.js tətbiqi. Resept məlumatları TheMealDB-dən, istifadəçi girişi və qeydiyyat Firebase Authentication-dan alınır.

## Xüs özelliklər

- Reseptləri axtarmaq və kateqoriyalara görə filtrləmək
- Resept təlimatlarına və detallara baxmaq
- Firebase ilə qeydiyyat və giriş
- Yüklənmə və xəta vəziyyətlərinin göstərilməsi

## Texnologiyalar

- Next.js
- React
- Firebase Authentication
- TheMealDB API
